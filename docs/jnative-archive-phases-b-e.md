# JNative Archive — 阶段 B–E 计划

作者：张晓达

承接阶段 A（`docs/jnative-archive-phase-a.md`）。引擎与任务逻辑必须被 CLI/GUI/右键共用；禁止用外部 `zip`/`7z` 冒充运行时；禁止把密码拼进命令行。

## 阶段 B — ZIP AES、大文件、取消与异常

- 产品化 AES：创建确认密码、解压可重试；空密码拒绝；不降级 ZipCrypto；密码生命周期（原生 wipe、不入日志/历史/argv）。
- ZIP64：>4GiB 单文件、>65535 条目夹具与互操作。
- 任务模型：进度（字节/速度/当前文件）、取消、覆盖策略；临时文件完成校验后再发布；取消不删任务前已有文件。
- 解压加固：路径逃逸、链接/联接、展开大小与磁盘预算、大小写冲突、超长路径。
- CLI：`--password` 仅经安全通道（交互/FD），扩展 `test`/`extract` 错误码。
- 验收：错误密码/截断/CRC 失败不得报成功；Mac↔外部工具哈希一致。

## 阶段 C — Mac / Windows 原生 GUI

- 同一 ZipLib + 任务引擎；JNative UI 控件扩展，不另起框架只留启动器。
- 打开/添加/压缩/解压/测试；条目虚拟列表；拖放；预设与密码对话框；后台任务列表与限频进度。
- 耗时操作不阻塞 UI。
- 分平台构建与签名说明；各自 E2E，互不顶替。

## 阶段 D — 右键集成与安装包

**Windows**

- 经典菜单 + Windows 11 现代菜单（`IExplorerCommand` / 应用身份）分别说明安装条件。
- 多选安全传参；扩展只启动主程序/工作进程，不在 Explorer 内压缩。
- 安装、升级、卸载无残留入口。

**macOS**

- 优先 Finder 快速操作/服务；若用 Finder Sync，明确监控范围，不宣称覆盖全部位置。
- 扩展只投递任务；签名、权限与启用步骤文档化。

右键直压/解压同样弹密码框、显示进度与失败详情。

## 阶段 E — 7z / LZMA2 与优化

- 仅在完整 7-Zip 引擎（非任意「LZMA SDK」切片）验证通过后启用：7z/LZMA2、加密、可选文件名加密。
- 固定版本、构建选项、来源与 THIRD_PARTY；可复现双平台产物。
- 基准：文本、大量小文件、大二进制、JPEG/视频/已压缩包、中文路径；记录大小/时间/峰值内存/CPU；与同条件成熟工具对比。
- ZIP 并行压缩：有界队列 + 内存预算；不无限缓存。
- RAR：首版不写；读仅在引擎真实支持且测试通过后加入。

## 跨阶段验收清单（摘要）

空文件/空目录/中文/长路径；>4GiB 与条目数；密码正误；截断与损坏；磁盘满/权限/冲突/取消；恶意路径与链接；双向互操作；无 JVM/无外部压缩工具可运行；安装后右键可用、卸载无残留。
