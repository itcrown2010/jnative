# 第 04 章：项目目录、入口方法和输出

## 本章目标

会用项目模式 build。读完后你应能独立完成章末检查项。

## 前置知识

请先完成前面章节；工具链版本 **JNative 0.32**（macOS arm64 已验证）。

`jnative new` 生成 `jnative.toml`、`jnative.project`、`src/Main.jn`。

教程示例项目在 `examples/tutorial/04-project/`。

```bash
cd examples/tutorial/04-project
java -jar ../../../target/jnative.jar build
./build/tutorial-04
```

`main(String[] args)` 是程序入口；`args` 为命令行参数（**已验证**）。交互式标准输入不作主线。


## 完整可运行代码

文件：`examples/tutorial/04-project/src/Main.jn`

```jn
public class Main {
    public static void main(String[] args) {
        System.out.println("project ok");
        System.out.println("argc=" + String.valueOf(args.length));
    }
}
```

## 文件名及运行命令

```bash
cd examples/tutorial/04-project
java -jar ../../../target/jnative.jar build
./build/tutorial-04
```

## 精确预期输出

```text
project ok
argc=0
```

## 代码关键部分解释

见上文注释与「概念」段。示例以 `examples/tutorial/` 为唯一事实来源。

## 常见错误及实际诊断

- 找不到 `target/jnative.jar`：先在仓库根 `mvn -DskipTests package`。
- 路径错误：命令中的相对路径相对于仓库根。

## 练习

1. 修改 Hello 输出为自己的名字并重新运行。
2. 故意制造一个类型错误，读懂诊断中的行号。

## 参考答案或可运行解法

练习 1：改 `System.out.println` 字符串即可。练习 2：参见 `05-errors/Bad.jn`。
