# JNative Task Monitor — W11 任务管理器对照清单

**目标：** 与指定 Windows 11 任务管理器版本尽可能一致的界面、交互与功能。  
**本轮范围：** 浅色 **进程页** 高一致性骨架；其他页导航可见但不得用假数据冒充。  
**E2E：** `WINDOWS_E2E_UNVERIFIED`（需 Parallel / Windows 主机同条件对照）。

| 整机 CPU/内存 | `GetSystemTimes` / `GlobalMemoryStatusEx` | 同上 | % / 字节 | 摘要条 | |
| 磁盘 | — | — | — | — | **未实现**：不用进程 I/O 字节冒充磁盘吞吐 |

## 与参考的已知差异（代码层）

1. 双层表头为摘要 `HBox` + 单行 ListView 表头，非原生双行 Header。  
2. 分组非 AUMID；结束应用组按同 path/主窗口启发式收集 PID。  
3. 磁盘/网络列固定「—」。  
4. 深色/高对比度未做。  
5. 视觉像素级一致 **未验证**（无 Windows 同条件叠图）。

## 后续推进顺序（固定）

进程页 → 性能页 → 详细信息 → 服务/用户 → 启动应用/历史记录 → 设置。
