# Feature completion policy

A feature is **not complete** when only the compiler accepts it.

```text
Feature Complete =
    Implementation
  + Tests
  + Example
  + Documentation
  + Release notes
```

If any part is missing, report the feature as **incomplete** in the capability matrix (Experimental/Partial) even if code exists.
