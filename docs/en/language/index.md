# Language Tour

Learn the **language** (syntax and semantics)—not how to call the HTTP SDK.

## Stability

Core OOP + control flow: **Stable** on verified hosts. Generics/lambdas/concurrency/FFI: **Experimental**. Full Java SE: **Not Supported**.
