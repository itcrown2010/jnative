# Package manager

**Status:** Experimental

## Current functionality

CLI surface exists: `add`, `remove`, `update`, `deps`, `search`, `info`, `publish`, `audit`, `licenses` (see `--help`). Local registry samples exist under example trees (e.g. `examples/ui-controls-pkg/registry`).

## Planned / incomplete

Remote ecosystem maturity, multi-OS verification, and lockfile UX are **not** claimed as Stable. Treat coordinates separately from language `package` declarations.

Inspect `io.jnative.pkg` and example registries before relying on a workflow.
