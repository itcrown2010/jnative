# What Can I Build with JNative?

Derived from tests and runnable examples (see [capability matrix](reference/capability-matrix.md)). Not marketing.

| Surface | Status | Evidence |
|---------|--------|----------|
| CLI tools | ✅ Build today | Hello, notes-cli, cli-todo |
| Native utilities | ✅ Build today | File I/O examples |
| File applications | ✅ Build today | `File.*`, file-io, notes-cli |
| Network programs (TCP) | ✅ / 🟡 | EchoServer, tcp-echo, Network e2e |
| HTTP services | 🟡 Experimental | HttpServer, http-server example |
| JSON (string-heavy) | 🟡 Experimental | json-demo; numbers gap noted |
| Concurrency (native) | 🟡 Experimental | multithreading example |
| Desktop GUI | 🟡 Experimental | macOS samples |
| Browser / wasm apps | 🟡 Experimental | guide-tasks / sudoku |
| Mobile (WebView+wasm) | 🔵 Experimental container | **Not** native UI SDK |
| WebSocket apps | ❌ Not Supported | — |
| Full Java SE / JARs | ❌ Not Supported | product position |
| Production auth/DB suite | 🔵 / blockers | see release blockers |

Legend: ✅ proven · 🟡 works, immature · 🔵 experimental / limited · ❌ not supported
