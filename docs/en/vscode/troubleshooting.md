# VS Code troubleshooting

| Issue | Action |
|-------|--------|
| Commands missing | VSIX not installed / wrong window |
| Wrong Java highlighting | File outside JNative project root |
| Toolchain red | Fix `jnative.jarPath`; run Check toolchain |
| Mobile build fails | SDK missing — see [../mobile/overview.md](../mobile/overview.md) |
