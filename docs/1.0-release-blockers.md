# JNative 1.0 Release Blockers

**Audit date:** 2026-10-08  
**Rule:** P0 > 0 ⇒ cannot release. Core Stable P1 should be 0 or explicitly accepted with risk.

---

## Summary

| Severity | Count | Release impact |
|---|---|---|
| **P0** | **8** | Hard blockers |
| **P1** | **14** | Core Stable should clear before RC |
| P2 | see architecture-debt | Capability gaps |
| P3 | deferred | 1.1+ |

## P0 — Release blockers

### B-P0-01 — No multi-platform CI / zero VERIFIED secondary OS

| Field | Value |
|---|---|
| ID | B-P0-01 |
| Subsystem | Release engineering / Platform |
| Severity | P0 |
| Description | Repository has **no** `.github/workflows` (or other CI). Linux x64, Windows x64, macOS x64 are not gated. |
| Evidence | `ls .github` → absent; Round4 matrix NOT VERIFIED |
| User Impact | “Works on my Mac” shipped as 1.0; silent breakage elsewhere |
| Fix Required | CI matrix: macOS arm64 + Linux x64 + Windows x64 at minimum; fail on e2e |
| Verification | Green CI artifacts on all required platforms |

### B-P0-02 — Windows runtime incomplete (no GC, sockets stub, no TLS, IOCP stub)

| Field | Value |
|---|---|
| ID | B-P0-02 |
| Subsystem | Runtime / Native |
| Severity | P0 |
| Description | `native/windows/` has fs/ui/poll_iocp/socket stubs; **no** `jnative_gc*`; sockets return “not implemented”; no TLS; IOCP PARTIAL. |
| Evidence | `native/windows/*`; `jnative_socket.c` error strings; `jnative_poll_iocp.c` PARTIAL |
| User Impact | Windows 1.0 claim is unsafe / non-functional for managed apps |
| Fix Required | Windows GC port **or** officially drop Windows from 1.0 matrix (document Unsupported) |
| Verification | Native hello + GC stress + TCP/TLS e2e on Windows CI |

### B-P0-03 — Linux EventLoop epoll is a stub

| Field | Value |
|---|---|
| ID | B-P0-03 |
| Subsystem | Async / Networking |
| Severity | P0 |
| Description | `jnative_poll_epoll.c` create/destroy/wakeup only; wait returns 0; no fd integration. |
| Evidence | File header “PARTIAL”; Round3/4 docs |
| User Impact | Async servers unusable on Linux |
| Fix Required | Real epoll wait/register/timer parity with kqueue |
| Verification | Async + HTTP e2e on Linux CI |

### B-P0-04 — Password KDF default is insecure (PBKDF2 500 iterations)

| Field | Value |
|---|---|
| ID | B-P0-04 |
| Subsystem | Security / Crypto / Auth |
| Severity | P0 |
| Description | `CryptoLib.DEFAULT_ITERATIONS = 500` with comment that higher counts risk native crashes; Argon2id “planned”. |
| Evidence | `stdlib/crypto/CryptoLib.java` ~740–743; scheduler validation: Argon2id MISSING |
| User Impact | Auth demos teach unsafe password storage |
| Fix Required | Safe default (≥OWASP guidance) via native KDF **or** refuse to ship Auth as Stable; block event loop appropriately |
| Verification | Native e2e hashing + Auth docs; no plaintext logs |

### B-P0-05 — PostgreSQL SCRAM unsupported + no live server e2e

| Field | Value |
|---|---|

## Explicit non-blockers for 1.0 (defer OK)

These must be labeled Unsupported/Experimental — **not** silently half-shipped:

- enum, switch, ternary, bitwise/shift, varargs, records, pattern matching  
- LinkedList / PriorityQueue / LinkedHashMap  
- DirectByteBuffer  
- HTTP/2 production  
- Redis / Kafka / MySQL  
- Full Studio IDE / Explorer Hardened  
- Self-hosting the compiler
