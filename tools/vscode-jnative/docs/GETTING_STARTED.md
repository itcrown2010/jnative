# JNative VS Code 入门（随包文档）

插件版本见扩展「JNative 入门」页。本文不包含虚构的在线下载链接。

## 1. 配置 SDK

在设置中任选其一：

- `jnative.executablePath`：可执行入口或 `scripts/jnative.sh`
- `jnative.jarPath` + `jnative.javaPath`：指向已构建的 `jnative.jar`

然后执行 **JNative: 检查工具链**。

## 2. 创建并运行 Web 项目（第一里程碑）

1. **JNative: 打开入门** → **创建 Web 项目**（整数加法器）
2. 打开新窗口后执行 **JNative: 运行**
3. 在预览页输入两个整数并点击「相加」
4. 修改 `src/App.java` 的 `add`，重新运行并刷新页面验证

## 3. 桌面项目（第二里程碑）

1. **创建桌面项目**
2. **构建** / **运行** → 原生窗口
3. **调试** 需安装 CodeLLDB；构建失败不会启动旧二进制

## 4. 移动项目（第三里程碑）

1. **创建移动项目**（CLI 官方 mobile 模板，同一加法业务）
2. **检查移动工具链**
3. Web 预览或选择设备后 **构建移动目标** / **运行移动应用**
4. 移动容器编译为 wasm32-browser，**不是**完整原生移动运行时

## 5. 错误与停止

- 构建诊断进入 **Problems**，点击定位源码
- **JNative: 停止** 仅结束本扩展启动的原生进程与 Web 预览服务
- 语言服务失败：状态栏可见，可用 **重启语言服务**
