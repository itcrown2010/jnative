# 第 05 章：如何读懂编译错误

## 本章目标

能定位行列。读完后你应能独立完成章末检查项。

## 前置知识

请先完成前面章节；工具链版本 **JNative 0.32**（macOS arm64 已验证）。

故意写错类型：

运行：

```bash
java -jar target/jnative.jar examples/tutorial/05-errors/Bad.jn -o /tmp/Bad
```

预期诊断含：`incompatible types: String cannot be converted to int`，并带 `file:line:col:`。

格式可被 VS Code problem matcher 解析。


## 完整可运行代码

文件：`examples/tutorial/05-errors/Bad.jn`

```jn
public class Bad {
    public static void main(String[] args) {
        int x = "oops";
    }
}
```

## 运行命令（负例）

```bash
java -jar target/jnative.jar examples/tutorial/05-errors/Bad.jn -o /tmp/Bad
```

预期：**编译失败**，诊断含 `String cannot be converted to int`。

## 代码关键部分解释

见上文注释与「概念」段。示例以 `examples/tutorial/` 为唯一事实来源。

## 常见错误及实际诊断

- 找不到 `target/jnative.jar`：先在仓库根 `mvn -DskipTests package`。
- 路径错误：命令中的相对路径相对于仓库根。

## 练习

1. 修改 Hello 输出为自己的名字并重新运行。
2. 故意制造一个类型错误，读懂诊断中的行号。

## 参考答案或可运行解法

练习 1：改 `System.out.println` 字符串即可。练习 2：参见 `05-errors/Bad.jn`。
