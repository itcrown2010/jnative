# 文档验证

## 自动化（第一阶段）

在仓库根：

```bash
./scripts/docs/verify-phase1.sh
```

预期检查：

1. `jnative --version` 可读  
2. `doctor` 退出成功（或记录跳过原因）  
3. `examples/guide-hello` 重新构建并运行，输出匹配  
4. API 提取脚本成功  
5. `website` 依赖安装后 `npm run build` 成功  

## 人工检查清单

- [ ] 侧栏上一篇/下一篇合理  
- [ ] 站内链接无大量死链  
- [ ] 代码块未声称未支持语法「可运行」  
- [ ] 截图（若有）来自当前版本  
- [ ] 构建产物不含密钥或真实业务数据  

## 平台分环境记录

在外部 CI 或贡献者机器上跑通时，追加：OS、arch、命令、日期、结果（通过/失败/跳过）。
