# GC、对象生命周期与线程安全边界

## 概念

原生目标使用带安全点的 GC（多线程下 STW 根扫描为既有能力说明）。对象在无引用后可被回收；与 FFI/UI 句柄交织时需明确所有权。

## 适用场景

- 普通托管对象：交给 GC。
- 原生资源（文件、窗口、WASM 句柄）：显式关闭/销毁。
- 跨线程：用文档认可的同步原语；UI 控件仅在 UI 线程触摸。

## 最小实践

```java
// 伪模式（请结合具体 API）：
// 1. 在 UI 线程创建控件
// 2. 后台计算完成后投递回 UI 线程更新
// 3. 窗口关闭后取消回调，避免触碰已销毁对象
```

具体 API 见桌面/Web 教程（阶段 2/3）。

## 明确语义

- `@NoGC` 区域省略部分安全点（高级；见 effects 文档）——入门勿用。
- WASM 线性内存与句柄生命周期见 Web 教程第 9 课（占位）。

## 常见错误

- 窗口销毁后仍执行闭包改 UI。
- 在持有原生锁时分配大量托管对象导致长时间 STW（性能章）。

## 支持限制

跨线程对象发布模型未承诺与 JMM 等同。**实验性**。
