# Web 第 02 课：编译并启动本地预览

## 步骤

```bash
./examples/guide-tasks/scripts/build_web.sh
cd examples/guide-tasks/web/dist
python3 -m http.server 8767
```

浏览器打开 `http://127.0.0.1:8767/`。

## 预期

状态「就绪（WASM TaskCore）」；`verify_web.sh` 打印 `GUIDE_TASKS_WASM_OK`。

## 常见失败

| 症状 | 处理 |
|------|------|
| 缺 `wat2wasm` | 安装 WABT；脚本会找 Homebrew 路径 |
| file:// 打开失败 | 必须用 HTTP 静态服务（CORS / ES module） |
