# Web 第 10 课：构建及部署说明

## 构建

```bash
./examples/guide-tasks/scripts/build_web.sh
./examples/guide-tasks/scripts/verify_web.sh
```

产物：`examples/guide-tasks/web/dist/`（`app.wasm`、`app.js`、壳文件）。

## 部署

将 `dist/` 放到任意静态文件服务器。  
**文档站本身不自动公开部署**；应用托管由你方运维负责。注意 HTTPS、缓存与 MIME（`.wasm` → `application/wasm`）。
