# 桌面第 03 课：表单输入与校验

## 本课目标

把输入交给 `TaskCore.addTaskString`，按错误码更新状态标签。

## 前置 / 工作量

02；核心 API 已存在。约 15 分钟。

## 代码状态

终稿 `TasksActions.addFromInput`。

## 步骤要点

1. `String t = TasksUi.input.getText();`
2. `int id = TaskCore.addTaskString(t);`
3. `id < 0` 时读 `TaskCore.getLastError()`：`2` 空标题，`3` 过长，`4` 已满。

## 为什么这样设计

校验在 **共享核心**，桌面只负责展示，Web 可复用同一错误码。

## 运行 / 预期

空输入点添加 → 状态「标题不能为空」。

## 完成检查

- [ ] 空标题被拒绝  
- [ ] 合法标题返回 `id >= 0`
