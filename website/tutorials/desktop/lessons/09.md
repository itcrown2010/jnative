# 桌面第 09 课：调试

## 本课目标

对合并源码或单文件使用 `--debug -O0`，在 LLDB / CodeLLDB 下断点。

## 步骤

```bash
# 合并产物路径见 build_desktop.sh
java -jar target/jnative.jar build/guide-tasks/merged-desktop.java \
  -o build/guide-tasks/TasksDesktop-dbg --app-type gui --debug -O0
lldb build/guide-tasks/TasksDesktop-dbg
```

VS Code：配置 `jnative.jarPath` 后「调试项目」（需 CodeLLDB）。

## 限制

对象字段可视化、异步栈：**未支持**。详见 [调试参考](/reference/debugging)。
