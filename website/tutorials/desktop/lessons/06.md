# 桌面第 06 课：本地存储

## 本课目标

用 `TaskCore.prepareSave` / `loadSave` + `File.writeString` / `readString`。

## 要点

- 存档路径默认 `build/guide-tasks/tasks-save.txt`
- 拼字符串时用 `TaskCore.unitToString`（**不要** `String.valueOf((char)c)`，会变成数字文本）
- 加载前 `File.exists`

## 运行 / 预期

点「保存」→ 状态显示路径；重启应用点「加载」→ 列表恢复。

## 完成检查

- [ ] 保存文件存在且可加载
