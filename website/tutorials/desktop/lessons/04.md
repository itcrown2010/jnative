# 桌面第 04 课：列表新增、编辑、删除

## 本课目标

`refreshList` 重建行；每行「完成 / 改 / 删」。

## 代码位置

终稿 `TasksActions.refreshList`、`makeRow`。

## 步骤要点

- 新增成功后 `refreshList()`
- 编辑：用输入框文本 `TaskCore.setTitleString(idx, t)`
- 删除：`TaskCore.removeAt(idx)` 后刷新
- 闭包捕获 `final int idx = index`（或等价 effectively final）

## 预期

添加多条后可见多行；删一行后数量减少。

## 完成检查

- [ ] 增删改各成功一次
