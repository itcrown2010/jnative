# 桌面第 02 课：布局与基础控件

## 本课目标

用 `VBox` / `HBox` 组织 `TextField`、`Button`、`Label`。

## 前置 / 工作量

完成 01；约 20 分钟。

## 代码状态

以 01 为起点；终点对照终稿 `examples/guide-tasks/desktop/TasksDesktop.java` 中 `TasksWindow.show` 的 `form` / `tools` 段。

## 要修改的文件

在 `TasksDesktop.java` 的 `root` 上 **插入**（非整文件，除非你直接使用终稿）：

- `TextField input`
- `Button addBtn`
- `HBox form` 容纳二者
- 状态 `Label status`

## 完整操作步骤

推荐直接阅读并运行终稿（避免半成品无法编译）：

```bash
./examples/guide-tasks/scripts/build_desktop.sh
```

对照源码中：

```text
HBox form → input + addBtn
HBox tools → save / load / bg
VBox listBox
```

## 为什么这样设计

先保证布局树挂到 `Window.setContent`，再接线事件（第 05 课）。

## 运行命令

`./build/guide-tasks/TasksDesktop`

## 预期界面

顶部标题与状态、输入行、工具行、列表区。

## 常见失败

控件未 `add` 到父容器 → 不显示。
