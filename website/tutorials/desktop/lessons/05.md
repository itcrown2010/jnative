# 桌面第 05 课：事件与闭包

## 本课目标

区分 `onClick` 与可取消的 `subscribeClick`；窗口关闭时释放。

## 代码位置

```java
TasksUi.addSub = TasksUi.addBtn.subscribeClick(() -> { TasksActions.addFromInput(); });
TasksUi.window.onClose(() -> {
    TasksUi.alive = 0;
    TasksUi.bgToken = TasksUi.bgToken + 1;
    if (TasksUi.addSub != null) {
        TasksUi.addSub.cancel();
        TasksUi.addSub = null;
    }
});
```

## 为什么这样设计

避免窗口销毁后闭包仍改 UI；与 UI 线程章节呼应。
