# 桌面第 01 课：创建窗口

## 本课目标

创建 `Application` + `Window`，显示标题标签并进入事件循环。

## 前置条件及预计工作量

- 已完成 [安装](/guide/install) 与 `jnative doctor`
- macOS arm64（本课验证平台）
- 约 15 分钟

## 本课开始时的代码状态

空目录，或从仓库复制终点：

`examples/guide-tasks/desktop/lessons/01/TasksDesktop.java`

## 要修改的文件

- **替换完整文件**：`TasksDesktop.java`（见下方）

## 完整操作步骤

1. 将下列内容写入 `TasksDesktop.java`（**整文件替换**）。
2. 编译运行：

```bash
java -jar target/jnative.jar \
  examples/guide-tasks/desktop/lessons/01/TasksDesktop.java \
  -o build/guide-tasks/Lesson01 --app-type gui -O0
./build/guide-tasks/Lesson01
```

### 完整文件

```java
public class TasksDesktop {
    public static void main(String[] args) {
        Theme.setAppearanceMode(Theme.MODE_LIGHT);
        Application app = new Application();
        Window w = new Window("JNative 任务管理器", 480, 320);
        Label title = new Label("小型任务管理器");
        title.setDisplayStyle(20, 0, -14935529);
        VBox root = new VBox();
        root.spacing = 12;
        root.padding = 16;
        root.add(title);
        w.setContent(root);
        w.show();
        app.run();
    }
}
```

## 为什么这样设计

`app.run()` 阻塞在原生 UI 循环；窗口必须先 `setContent` 再 `show`。类型来自嵌入 stdlib，无需 `import jnative.ui.*` FQN（与数独桌面相同）。

见上。

## 预期输出或界面

浅色窗口，标题「小型任务管理器」。无控制台业务输出。

## 常见失败及排查

| 症状 | 处理 |
|------|------|
| 无窗口 | 确认 `--app-type gui`；勿在无图形会话的 SSH 环境期望窗口 |
| doctor 失败 | 先修 clang/LLVM |
