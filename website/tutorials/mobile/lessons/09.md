# 移动第 09 课：模拟器及设备运行

## Android：构建 vs 安装（分开）

### 构建（本机已验证）

```bash
./examples/guide-tasks/scripts/build_android.sh
# APK: mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

### 安装到设备/模拟器（请本机执行；文档标 **未验证交互**）

```bash
adb devices
adb install -r examples/guide-tasks/mobile/android/app/build/outputs/apk/debug/app-debug.apk
```

## iOS：模拟器 vs 真机签名（分开）

### 模拟器构建（本机曾 OK）

```bash
./examples/guide-tasks/scripts/build_ios.sh
# 或指定：IOS_DESTINATION='platform=iOS Simulator,name=iPhone 15' ...
```

在 Xcode 中 Run 到模拟器以做交互（构建脚本本身不启动 UI 自动化）。

### 真机

1. 在 Xcode 选择 Team / Bundle ID  
2. 连接设备，信任开发者证书（设置 → 通用 → VPN 与设备管理）  
3. 参考数独：`examples/sudoku/scripts/install_ios_device.sh`  
4. guide-tasks 真机安装：**未验证**
