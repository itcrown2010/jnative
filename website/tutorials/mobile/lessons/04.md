# 移动第 04 课：本地资源加载

## 步骤

```bash
./examples/guide-tasks/scripts/sync_mobile_assets.sh
```

将 `app.wasm` / `app.js` + 触屏壳写入：

- `mobile/android/app/src/main/assets/www/`
- `mobile/ios/Calculator/www/`
- `mobile/staging/*-www/`（可单独用 HTTP 预览）

## 预期

www 内仅任务触屏资源（无残留 sudoku.css）。

## 浏览器预览（无设备时）

```bash
cd examples/guide-tasks/mobile/staging/android-www
python3 -m http.server 8768
```
