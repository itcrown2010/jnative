# 移动第 02 课：Android / iOS 工具链检查

## 步骤

```bash
java -jar target/jnative.jar doctor --mobile
# 或 jnative doctor --mobile
```

本机成功时可见：`target web/android/ios: available`，且 **不会**自动下载 SDK 或改签名。

## 预期

Compiler、wat2wasm、Android SDK、adb、Xcode、Simulator 等按你机器显示 ✓/缺失项。
