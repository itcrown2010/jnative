# 移动第 07 课：平台能力桥接

## 要点

guide-tasks 触屏壳默认用 **WebView `localStorage`**，不强制桥接。  
数独容器带 `JNativeBridge` / `JNativeHost`（存储、平台名等）——模式参考 `examples/sudoku/mobile/`。

规则：

- 桥接只做平台能力，**不**重写 TaskCore 规则
- 销毁 WebView 时释放 bridge（见 iOS `deinit` / Android `onDestroy`）
