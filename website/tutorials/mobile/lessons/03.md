# 移动第 03 课：WebView / WKWebView 容器

## 要点

| 平台 | 入口 | 加载方式 |
|------|------|----------|
| Android | `MainActivity.kt` | `WebViewAssetLoader` → `https://appassets.androidplatform.net/...` |
| iOS | `ViewController.swift` | 自定义 `jnative-app` scheme + `LocalSchemeHandler`（避免 `file://` 黑屏） |

容器只负责：JS 开关、桥接注入、生命周期事件、安全区 padding。

## 代码位置

- `examples/guide-tasks/mobile/android/.../MainActivity.kt`
- `examples/guide-tasks/mobile/ios/Calculator/ViewController.swift`
