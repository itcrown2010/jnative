# 移动第 10 课：调试与打包

## 调试

| 目标 | 方式 |
|------|------|
| WASM / JS | Safari Web Inspector（iOS）、`chrome://inspect`（Android WebView） |
| 原生容器 | Xcode / Android Studio 断点（壳代码） |
| 资源是否最新 | 重新 `sync_mobile_assets.sh` 再装包 |

不要为「能跑起来」建议关闭 ATS 全局明文或关闭签名校验。

## 打包检查清单

- [ ] `verify_mobile_assets.sh` OK  
- [ ] Android APK 或 iOS Simulator 构建成功  
- [ ] 版本号与 `TaskCore` 同源（勿混用旧 wasm）  
- [ ] 产物不含真实业务密钥  

## 完成检查

- [ ] 能向他人说明：容器 ≠ 原生 UI  
- [ ] 知道设备安装与 `assembleDebug` 不是同一步
