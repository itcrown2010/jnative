# public/js/components/document (UI 1.2)

作者：张晓达

Strong-typed document UI without eval:

- `definition.js` — DocumentUiDefinition for SalesOrder, PurchaseOrder, Delivery, GoodsReceipt, ARInvoice, APInvoice
- `calc.js` — DocumentCalculationService (integer cents, half-up)
- `selectors.js` — Item / BusinessPartner / Warehouse / Employee pickers
- `editor.js` — DocumentEditor shell (header, lines, footer, toolbar, panels)
