# 奇想校园 · 商业化完善路线图（产品 + 研发）

作者：张晓达　　范围：儿童素质教育（画画/英语/语文/数学）多校区机构 SaaS

## 1. 现状差距（对照"可卖给机构"的最低标准）

| 维度 | 现状 | 商业化缺口 | 本轮处理 |
|------|------|-----------|----------|
| 账号 | 仅 demo 免密登录 | 无真实账号体系 | 账号+密码登录、邀请码注册（家长/员工）、改密、个人资料 |
| 学员 | 只能读列表 | 无法新增/编辑/档案/家长绑定 | 学员档案 CRUD、家长邀请、学员详情聚合页 |
| 课程/班级 | 仅种子数据 | 无法维护 | 课程、班级、教室、员工 CRUD |
| 销售 | 手工建合同 | 无商品价目、无招生线索 | 商品套餐、线索 CRM（跟进/试听/转化） |
| 收费 | 有合同/收款/退款 | 无欠费/续费视图 | 欠费列表、续费预警、续费咨询 |
| 家校沟通 | 反馈+应用内通知 | 无公告、作业、评价 | 公告（含已读）、作业与点评、课后评价 |
| 经营 | 负责人只有计数 | 无报表 | 经营总览、日收入、出勤率、转化漏斗、课酬、CSV |
| 导航 | 4 个 Tab、功能藏在"我的" | 功能入口混乱 | 4 Tab（首页/工作/消息/我的），"工作"为角色功能 Hub |

## 2. 角色与信息架构

- **教务（ADMIN）**：首页（今日待办+关键数）→ 工作 Hub：学员、线索、课程班级、排课、请假、合同收款、续费预警、公告、员工。
- **负责人（DIRECTOR）**：首页（经营概览）→ 工作 Hub：经营报表、课酬、评价、续费预警、线索漏斗、导出。
- **老师（TEACHER）**：首页（下一节课/待反馈）→ 工作 Hub：本周课表、签到、反馈、作业、我的学员、我的课酬。
- **家长（PARENT）**：首页（孩子+下次课+余额）→ 工作 Hub：本周课表、请假、课时账、成长反馈、作业、公告、评价、续费咨询。

## 3. 关键业务规则（沿用 RULES.md，新增部分）

1. **账号**：`login` 为手机号或员工账号；密码使用 `Password.hashBlocking`；演示登录仅 `WC_ALLOW_DEMO_LOGIN=1`。
2. **邀请码**：教务为家长/员工生成一次性邀请码（72h 有效），注册后自动绑定学员或身份；邀请码单次使用。
3. **线索状态机**：`NEW → CONTACTED → TRIAL_BOOKED → TRIAL_DONE → WON | LOST`；`WON` 须关联转化学员；`LOST` 必须填原因。
4. **商品**：商品=可复用的课时包/学期模板；按商品报名生成合同快照，价格以商品为准，可手工优惠（记审计）。
5. **公告**：按校区/受众发布；已读按用户记录；撤回后不可见。
6. **作业**：老师布置（班级/个人）→ 家长提交（文字/图片 media）→ 老师点评+星级；家长仅可见自己孩子。
7. **评价**：已完成课次后家长可对老师/课程 1~5 星+留言，每课次每学员 1 次；老师仅见自己的汇总，负责人见全部。
8. **课酬**：按 `wc_teacher_rates`（每课次分）× 已完成课次统计，仅统计不付款。
9. **续费预警**：课时包剩余 ≤ 2 课时 或 ≤ 30 天到期；学期制距结束 ≤ 14 天。
10. **导出**：CSV 仅教务/负责人，按机构隔离，写审计。

## 4. 明确不做 / 未验证（保持诚实）

- 在线支付网关、APNs/FCM 推送、短信验证码（需外部商务资质）：**不做**，收款仍为人工登记。
- 真机签名、商店上架：**UNVERIFIED**。
- 多租户自助开通（SaaS 开户）：本轮仅单机构，`org_id` 隔离已就绪。

## 5. 里程碑

| 里程碑 | 内容 |
|--------|------|
| M1 账号与档案 | 登录/邀请/改密、学员/家长/员工/课程/班级/教室维护 |
| M2 销售闭环 | 商品、线索、试听、转化、一键报名收款 |
| M3 家校互动 | 公告、作业、评价、续费咨询 |
| M4 经营 | 报表、预警、课酬、导出 |
| M5 体验 | 4 Tab + Hub + 周历、模拟器验收 |
