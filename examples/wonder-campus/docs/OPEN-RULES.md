# 尚未确定的业务规则（不得当作既定事实）

作者：张晓达

以下规则**尚未由业务方确认**，本轮实现采用保守默认，并在代码/文档中可追溯；后续确认后应改规则快照默认值或迁移策略，而不是 silently 改历史合同。

| 议题 | 现状默认 | 说明 |
|------|----------|------|
| 六家机构是否同一法律主体 | **未确认** | `wc_orgs` = 运营组织；`wc_billing_entities` = 收款主体；合同/收款可关联不同主体 |
| 跨校区权益是否可通用 | **默认否** | 仅合同所属校区可用；跨校区需 `wc_campus_entitlement_grants` |
| 请假是否扣课时包 | 快照 `leaveConsumes=0` | 可按校改快照，不追溯旧合同 |
| 缺勤是否扣课时 | 快照 `absentConsumes=0` | 同上 |
| 迟到是否等同出勤扣课 | 本轮 `LATE` 与 `PRESENT` 均可消课（批量签到走 PRESENT） | 若需「迟到不扣」需改快照键 |
| 补课是否再次消课 | 补课仍按合同模式签到消课；原课请假默认不扣 | 禁止双免无限补课靠 `wc_makeup_credits` |
| 取消请假时已排补课 | 未签到/未完成则可取消并作废补课资格 | 已签到/已完成则拒绝取消 |
| 运营组织与校区品牌 | 六校区挂同一演示运营组织 | 若分主体运营需拆 `wc_orgs` |
| 3 岁～高三年龄校验 | 仅存 `age_band`，未强制准入规则 | 招生规则未做 |
| 外部 AI 处理儿童资料 | **禁止** | 本轮无任何外部 AI 调用 |
| APNs/FCM | **未做** | 仅应用内通知 + 可重试任务 |
| 真机相册选图 | **UNVERIFIED** | 仅媒体登记元数据 + 鉴权读取 |
